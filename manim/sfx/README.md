# Sound effects (self-synthesised, licence-free)

All WAVs here are generated by `make_sfx.py` from sines and seeded noise, so they are safe for public uploads.
Regenerate with `manim/.venv/bin/python manim/sfx/make_sfx.py`. That also rewrites `gains.json` (mix gains) and
`preview.wav` (every effect in a row at its real mix level, no normalisation, so it sounds quiet on its own). The videos have no voiceover; the captions carry the story.

**Principle: the effects support the picture, they never take the foreground.** Accents are rare and quiet.
Nothing loops or nags, and silence is fine.

| file | use it for | tier |
|---|---|---|
| `stone_big` | the single most important slam (the move-37 stone, opening and callback) | accent |
| `boom` | one giant reveal (10^360 vs 10^80) | accent |
| `success` | the main aha (79 % bar lights up) | accent |
| `chime` | a smaller aha (π reaches ≈3.14, "it found the only correct move") | accent |
| `stone` | an ordinary stone / X placed | event |
| `question` | a doubt beat ("这是失误吗？") | event |
| `whoosh` | a big scene change (between acts) | event |
| `riser` | the fast-forward run up to the reveal (end it as the reveal lands) | event |
| `dice` | the "Monte Carlo" name card | event |
| `shuffle` | cards dealt | event |
| `pop` | a new branch / mini board appearing (one per group, not one per node) | small |
| `card` | one card placed | small |
| `tick` | a counter step (≤ 4 per second) | small |
| `rain` | the random points falling in the π demo (one 2.5 s clip, not per point) | bed |
| `whoosh_soft` | a small slide between beats | bed |
| `ambient` | optional room-tone pad (32 s seamless loop; use `write_bed` for a video-length bed with fades) | bed |

## Usage in a Manim scene

```python
SFX_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "sfx")
with open(os.path.join(SFX_DIR, "gains.json")) as fh:
    SFX_GAIN = json.load(fh)

def sfx(self, name, offset=0.0, extra_db=0.0):
    # offset is seconds from the current scene time: use it to land the hit on the frame where the motion lands
    self.add_sound(os.path.join(SFX_DIR, name + ".wav"), time_offset=offset, gain=SFX_GAIN[name] + extra_db)
```

## Mixing rules

- **Sync:** the sound lands on the frame where the motion lands, e.g. the stone touches the board or the bar reaches 79 %. Use `offset`, not a sound before the animation starts.
- **Density:** at most one accent every 20 s and 4–5 accents per video. Leave at least 0.8 s between any two event-tier sounds. Small sounds go on groups, not on every element.
- **No stacking:** never play two accents at once. If an accent lands, skip the small sounds in the same 0.5 s.
- **Ambient (optional):** don't tile `ambient.wav` by hand. At the very end of `construct()`, write a bed of the exact
  length, with a 2.5 s fade-in and a 4 s fade-out, and drop it in at t = 0:
  ```python
  sys.path.insert(0, SFX_DIR); from make_sfx import write_bed
  bed = os.path.join(SFX_DIR, f"bed_{type(self).__name__}.wav")
  write_bed(self.time, bed)
  self.add_sound(bed, time_offset=-self.time, gain=SFX_GAIN["ambient"])
  ```
  It sits about 20 dB under the accents and 11–14 dB under ordinary events. `bed_*.wav` files are regenerated on
  every render.
- **Phones:** every sound keeps most of its level in the 250 Hz–8 kHz band. `boom` (−9 dB) and `stone_big` (−7 dB)
  lose the most, by design. `make_sfx.py` prints this as `phone-band`.
- `extra_db` adjusts a single use by a couple of dB. Don't raise the accent tier above its default.

## Mastering (do this on every final render)

The raw Manim mix of these quiet effects comes out at about −40 LUFS, which is nearly inaudible on a phone. As a last step:

```bash
python3 manim/sfx/master_audio.py in.mp4 out.mp4 --target -24 --peak -1.5
```

The chain is a gentle compressor (narrows the range, about 16 → 11 LU, so accents never jump out), then make-up gain
to −24 LUFS integrated, then a limiter at −1.5 dBTP. The video stream is copied, not re-encoded. The script asserts
the target was met. −24 LUFS keeps the effects in a supporting role next to normal platform content (−14 to −16);
use `--target -20` if a cut feels too quiet on a phone.
